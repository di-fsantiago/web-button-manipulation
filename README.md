# web-button-manipulation
Manipulação dinâmica de botões de diversas funcionalidades.

## 02. Tecnologias Utilizadas
- HTML5
- CSS3
- Javascript 

## 03. Como Instalar e Executar
Não é necessário instalar nenhuma dependência.

1. Clone este repositório:
   ```bash
   git clone https://github.com/di-fsantiago/web-button-manipulation.git
   ```

2. Acesse a pasta do projeto:

   ```bash
   cd web-button-manipulation/atividade-web
   ```

3. Abra o arquivo `index.html` em seu navegador.

## 04. Exemplo de Uso ou Demonstração
Ao abrir a página (index.html), você encontrará os seguintes botões interativos:
* Saiba Mais
* Mudar Cor
* Mudar Título
* Aumentar Texto
* Esconder Texto
* Mostrar Texto

Clique em qualquer botão para disparar sua respectiva funcionalidade.

> Nota: Para restaurar o estado original da página, basta recarregá-la (F5). A exceção é a dupla Esconder Texto e Mostrar Texto, que permite alternar a visibilidade do conteúdo em tempo real sem precisar atualizar a página.
